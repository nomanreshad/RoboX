### 🧠 **Things to Learn Alongside**
| Topic | Why |
|-------|-----|
| ✅ **Arduino Basics** | For writing, uploading, and debugging code on the Arduino Uno. |
| ✅ **PWM & Motor Control** | Control speed and direction of DC motors using L298N. |
| ✅ **Serial Communication (Bluetooth)** | For controlling the robot via phone using HC-05. |
| ✅ **Sensor Handling (Ultrasonic + Servo)** | To detect and avoid obstacles with HC-SR04 and rotate using SG90. |
| ✅ **Voltage Regulation** | To use LM2596 for safe 5V/12V power distribution. |
| ✅ **Android App Development** | To build own custom joystick/voice command app. |
| ✅ **Voice Recognition Integration (Offline/Phone Based)** | So RoboX can understand and act on your voice commands. |
| ✅ **Sound Output (Speaker / Buzzer)** | For RoboX to speak or give audio feedback via mobile-controlled commands. |
| ✅ **Circuit Protection (Diode, Fuse, Capacitor)** | To avoid short circuits, voltage spikes, and reverse polarity damage. |
| ✅ **Basic Electronics (Wires, Breadboard, LED, Switches)** | To manage clean circuit design, status indicators, and safe power toggling. |
| ✅ **Future Add-ons (ESP32-CAM, OLED)** | For future upgrades like video feed and display modules. |
